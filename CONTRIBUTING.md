# Contributing

## Setup

```
npm install
```

## Before submitting a change

```
npm run lint
npm test
```

Both must pass — the same commands run in CI on every push and pull request.

## Pull requests

- Branch off `main`, open a PR against `main`.
- Follow the PR template (Summary / Test plan).
- Keep commits focused; use clear, descriptive commit messages.

## Reporting issues

Use the issue templates (bug report or feature request) when opening an issue.
