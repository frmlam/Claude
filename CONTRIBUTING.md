# Contributing

Everyone participating is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Setup

```
npm install
```

## Before submitting a change

```
npm run lint
npm run format:check
npm test
```

All must pass — the same commands run in CI on every push and pull request.
Run `npm run format` to auto-fix formatting.

## Pull requests

- Branch off `main`, open a PR against `main`.
- Follow the PR template (Summary / Test plan).
- Keep commits focused; use clear, descriptive commit messages.

## Reporting issues

Use the issue templates (bug report or feature request) when opening an issue.
